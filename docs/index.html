Built for accurate Mac bandwidth reporting

MacNetSpeed is a lightweight menu bar bandwidth meter for people who need honest numbers: decimal byte units, stable right-aligned speeds, and totals that track what Activity Monitor shows for the same interfaces.

Download & upload in the menu bar Two-line status item with blue download and red upload, fixed width so changing digits do not shift left and right.
Data received & data sent Interface totals intended to match Activity Monitor’s Network pane for All interfaces or Wi‑Fi.
Activity Monitor–style graph Blue download above the center line, red upload below, shared scale for instant visual reading.
Top 20 apps on demand Per-app live connections stay off until you expand the list — then stop when the panel closes.
Performance friendly Utility-priority sampling and no continuous heavy flow accounting while the menu bar is idle.
Open at login Optional login item so your Mac network speed is visible every session.

How to download and install

  1. Download the latest MacNetSpeed.dmg from GitHub Releases.
  2. Open the disk image and drag MacNetSpeed into the Applications folder.
  3. Launch from Applications. If Gatekeeper warns, use Right‑click → Open once.
  4. Click the menu bar speeds to open the panel. Enable Open at login if you want it at startup.

Prefer source? Clone github.com/Inzamam-SEO/MacNetSpeed and run ./Scripts/build-dmg.sh.

Frequently asked questions

Is MacNetSpeed free?

Yes. MacNetSpeed is free under the MIT License, including commercial use with attribution via the license terms.

Does it match Activity Monitor?

Data received and data sent are designed to track Activity Monitor Network totals for the same interface selection. Live rates use your update interval; Activity Monitor may label some rates in kilobits (kb/s) while MacNetSpeed uses kilobytes (KB/s).

Will it slow down my Mac?

The menu-bar path is a small periodic interface read. Top 20 apps accounting runs only while that section is open.

Where can I get support?

Open an issue on the GitHub repository.
